# ⚔️ Petit héros

Aventure pixel art : épée, arc, bombes, donjons et boss. Se joue sur mobile (contrôles tactiles) et PC (clavier), même hors ligne.

▶️ **Jouer** : https://TON-PSEUDO.github.io/NOM-DU-REPO/

## Installer comme une app
- **Android (Chrome)** : menu ⋮ → « Installer l'application ».
- **iPhone (Safari)** : Partager → « Sur l'écran d'accueil ».

## Contrôles
Clavier : flèches/ZQSD pour bouger, Espace pour dasher, R pour la potion, M pour le son. Sur mobile : joystick et boutons à l'écran.

## Données
La progression est sauvegardée uniquement dans ton navigateur (localStorage). Aucune donnée n'est envoyée nulle part.
